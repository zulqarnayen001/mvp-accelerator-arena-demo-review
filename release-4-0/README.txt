M.V.P. ACCELERATOR: THE 14 MODULES (20261124a)
Getting Started and Lessons 1 to 6, for each track (Athleader and Player-Coach). Each module is its own package,
as it will ship to the LMS.

HOW TO OPEN IT
Open index.html in this folder (Chrome or Edge). It lists all 14 modules, each with two ways in:
  Learner view   every rule on, exactly as a learner will see it
  Review view    for review: Next, the menu and every video timeline are open
Each module ends on its own last screen, as it will in the LMS; come back to index.html for the next one.
Keep the folders together.

Each module keeps its own progress in this browser. Answers carry from lesson to lesson on the same device and
browser: the five words, the Lesson 1 starting line, the why (Athleader) or the one behavior (Player-Coach), the drill
answers and the Playbook answers. A lesson opened on another device asks for them again; every downloaded Playbook
ends with "Your season so far", which keeps them on any device.

Each lesson's Playbook pages are slides in the module: the learner types straight into them, and the filled-in
Playbook downloads as a PDF at the end of the lesson (and from the recap).

FOR THE LMS
Every module folder is also a SCORM 2004 4th Edition package: imsmanifest.xml, with index.html as the launch file.
The zips in _SCORM_packages are the upload files (they leave out the two review launch files).
  Completed     Getting Started when the pre-assessment code is in; Lessons 1 to 5 when that lesson's Pulse Check
                code is in; Lesson 6 when its Pulse Check and post-assessment codes are in and either the 180 code
                is in or the learner answers that their partner didn't take part (recorded as skipped)
  Reporting     Completed / Incomplete (no score, no pass or fail), as in the Storyline test package
  Resume        the learner's place (cmi.location) and answers (cmi.suspend_data)
  Interactions  knowledge check answers and choices
  Order         between modules, set in the LMS (for example a Showpad Path)
The videos stream from Vimeo (hidden on vimeo.com, playable only where the course embeds them), so a learner
needs an internet connection to watch them; if a network blocks Vimeo, the screen offers to open the video in a
new tab or to continue without it. Lesson packages are 20 to 30 MB.
_lms_test.html is a small SCORM test LMS for checking a package on this computer (served over http).
